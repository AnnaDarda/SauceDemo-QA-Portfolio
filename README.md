# SauceDemo-QA-Portfolio
This repository contains test cases and bug reports for the SauceDemo web application, demonstrating skills in QA, automation, and CI/CD workflows.

## Structure
- **TestCases/** → Detailed test cases for login, cart, and product functionalities.
- **BugReports/** → Documented bugs with reproduction steps, severity, and environment details.
- **Screenshots/** → Screenshots supporting bug reports and test cases.

## Tools & Skills Demonstrated
- Manual testing of web applications
- Bug reporting and documentation
- Test case design
- CI/CD concepts and automation familiarity
